# 赛马展开展示原型

本地入口：`http://127.0.0.1:5174/keiba/simulator`。

在 `frontend` 目录执行 `npm run dev -- --port 5174`。页面独立于公开比赛页，无需后端服务。已有页面文案保持不变，新增页面文案为日语。

## 数据

运行 `python scripts/prepare_simulator_demo.py` 从本地 Agent LLM 原始出马表与预测中的脚质字段，生成 `frontend/src/fixtures/raceSimulatorDemo.json`。当前提供新潟 2026-05-03 的 1、2、3 场。脚本仅写展示副本，不写预测、赛果、审计或 Render 快照目录。

近走仅保留日期严格早于目标比赛且并非目标比赛本身的记录。展示副本不含赔率、人气、预测总分或目标赛果。原始近走的历史名次属于允许使用的赛前资料。

## 模拟边界

`frontend/src/lib/raceSimulator.js` 是独立于现有打分与文字展望的展示用引擎，固定步长 0.2 秒。输入包括历史着顺相对位置、早段通角位置、同马场且距离相近的末段时间、距离经历与保存的脚质。缺失项使用中间值并扩大波动范围。速度、耐力、消耗、加速系数均为假设，尚未校准或验证预测精度。

## 真实走路资料（2026-11-01 核对）

新增 `frontend/src/fixtures/raceCourses.json`，覆盖中央十场、地方十四个平地场的四十四种草地／泥地、内／外、左／右走路。来源、核对日期、形状精度、断面精度逐配置保存。带广挽曳和障碍赛不套用此平地模型。

- 中央尺寸、方向、周长和直线来自各场 JRA 官方页面；草地统一使用官方基准走路尺寸。平面控制点根据官方图粗略重绘，不是 GIS 测绘。
- 中央高低断面由官方图片填色上缘数字化，以公表高低差归一化；约一百二十个初始取样点经垂直误差约束简化。盛冈按岩手竞马官方高低图取近似点。勾配是近似图的导数，不是另行测得的精密坡度。
- 地方官方公表平坦的走路使用零高低曲线。门别、笠松、园田、高知、佐贺目前只有已核对的总高低差，没有取得完整位置曲线；对应六种配置保留未知值，不伪造坡段，也不应用坡度速度或耗力修正。
- 新潟两千米等可能同时使用内外走路的距离，不做均值。原始资料缺少内外指定时，界面注明临时选择，并允许切换。
- 各比赛按公表周长沿赛道推进，可以经过终点线后继续下一圈。起点按距终点的剩余距离定位；引込线、特殊复合走路、当天栏杆配置尚未精确还原，界面明确标为近似。
- 可以保持原始出走马资料，另外选择比较走路及试跑距离；界面明确提示这是假设条件，原比赛资料不会修改。

坡度反应仍是可关闭的展示假设：速度修正为 `-18 × 坡度` 米／秒；体力消耗乘数为 `1 + 16 × 上坡坡度 + 4 × 下坡坡度`，限制在 0.85～1.8。坡度以米／米表示。官方数据仅支持地形，不支持这些生理反应系数；不能据此宣称预测改善。

主要来源：各场 `https://www.jra.go.jp/facilities/race/<场地英文>/course/index.html`、[地方竞马官方赛道指南](https://www.keiba.go.jp/guide/course/)、[盛冈官方资料](https://www.iwatekeiba.or.jp/oro_01)。每项具体图片地址也保存在资料包内。

如需重新生成，在保留已下载官方图的情况下运行 `python scripts/prepare_simulator_courses.py`。该脚本仅写前端展示资料，不改动预测、赛果、打分或审计目录。

每次模拟先产生完整轨迹，再播放或拖动定位。相同种子与条件可精确重播，“别的展开”改变种子。比赛节奏、领跑竞争和前程消耗会影响轨迹；不预设最终名次。进路取值及外绕成本为简化模型，不含碰撞、堵塞或真实赛道测绘。赛道总览按公表周长推进，形状近似、视觉高度夸张，马匹可经过终点后继续下一圈；编号引线用于避免文字重叠。

“馬群拡大”采用独立的显示布局，将密集马群排开，保留前后顺位和各马实际模拟差距的数值标注。显示的横向间隔和分排经过放大，不代表物理马间距离或真实内外跑位；不会改写模拟状态、速度、消耗、冲线时间或结果。默认“全体コース”展示所选真实走路的近似形状，缩小普通马匹的标记，仅突出选中马的编号。两种视图共用同一试跑和播放进度。

200 次统计使用同一条件、固定的种子序列，显示前三进入频次最高的五匹马。仅表示该模型内出现频率，不能解释为真实胜率或已完成回测。各马的推定身体能力与体力条均非实测值。

## 验证

在 `frontend` 执行：

```powershell
node --test tests/raceSimulator.test.js tests/racePackLayout.test.js tests/raceCourses.test.js
npm run build
```

覆盖全员冲线、距离和体力边界、种子复现、条件变化、随机结果变化、赔率/人气/目标赛果隔离、缺失及未来近走处理、拖动终点与实际计算顺位的一致性。

## 历史校准实验（2026-11-01）

已使用 5,615 场 Agent full 输入做校准与独立验证，详情见 [校准记录](race_simulator_calibration.md)。最近 1,216 场完全未参与调参。关闭随机时，完赛用时误差 3.48→1.93 秒、末段误差 3.64→1.14 秒、前五覆盖实际前三 64.86%→67.24%；但保留原随机波动后覆盖率 60.12%→57.32%。因此候选仅保存为研究结果，默认页面继续使用原参数。体力仍是潜在状态，坡度反应和进路等假设没有被校准。

引擎新增显式参数与不记录播放帧的计算接口，并记录进入最后 600 米的时刻；原默认动力学和界面文案保持原样。研究输入从近走重建脚质，结果不等于生产 Agent 排序的优化回测。
