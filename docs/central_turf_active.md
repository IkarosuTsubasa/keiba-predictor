# 中央草地正式模型

## 当前行为

中央草地使用 `central_turf_history_place_v1_20261025`。模型权重与此前已验证的历史表现候选完全相同，没有重新训练或另选参数。模型 SHA256：`81c5e44ef12e1abfe1f5bf495bcbb91449604c3d5f23a72f5003f95a7adcb652`。

- 目标是预测前五尽可能覆盖实际前三；分类信号直接排序，混合权重为 1，不保留旧本命。
- 新排序在生成印记、投注策略、马券、模拟和 LLM 解释之前完成。这些下游模块沿用既有规则，但读取新排序。
- 不再加载旧草地冠军模型、旧草地前三模型，也不再后台计算影子结果。基础分项仍作为新模型的部分输入，不等于继续运行旧模型。
- 地方、中央泥地走原来的分支，模型文件与参数不变。
- 全部无近走记录的中央草地也使用新模型的缺失值处理，不交给 LLM 另选排名；此类数据不足的比赛不代表准确率已经验证充分。
- 不改历史预测，不做批量重生成、不删除原始数据或审计。已在运行中的旧代码任务仍可能回传旧版本结果。

正式模型和校验元信息位于 `keiba_llm_agent/models/scope_reranker/`。292 维特征由 28 维分项、204 维连续历史及相对特征、60 维补充历史组成，不包含赔率、人气、身份或目标赛体重。启用市场分数的草地配置被拒绝；模型或输入校验失败时任务报错，不静默生成旧排序。

页面总分仍沿用原有排序映射分数，不把未经校准的分类信号宣传为真实前三概率。马券玩法、资金分配和信心算法没有在这次切换中重新优化。

## 部署生效

推送后由现有 Render 自动部署。远程预测由 GitHub Actions 检出对应分支代码执行；使用新代码启动的后续草地任务默认正式启用，不需要设置额外开关。`KEIBA_CENTRAL_TURF_SHADOW_MODE` 不再生效，历史总重排环境开关不关闭正式草地分支；其对地方和泥地的原有含义保留。底层 Python 的显式 `scope_reranker_enabled=False` 仍供离线分项实验使用，不是正常预测任务的默认值。

检查新预测的 `scope_reranker_result.model_version` 应为上述新版本，且 `applied=true`，`scope_reranker_config.mode=active`。首次线上回传与部署状态需要另行观测，代码推送成功不等于已确认远端首场生成成功。

## 数据与回溯

完整审计继续保存原始 `race_data`、各项分析、评分配置和最终预测。新推理记录位于 `model_inference.central_turf_history`，保存正式模型版本、模型及源码哈希、训练截止日期、292 维特征及哈希、历史数据状态、分类信号、最终排序和前五；留档不会再次调用模型预测。现有阶段和版本化回传、结算继续保留这些扩展字段。含正式推理记录的早期审计及预测增加清理豁免，失败状态也保留；原有 `shadow_predictions` 历史记录不删除。本次不执行真实数据清理。

这次发布使用截至 2026-10-25 的全部 630 场合格中央草地 full、8,324 条出走观察训练出的冻结模型。此前折外证据见[补录验证报告](turf_supplement_validation_20261025_zh.md)。本次部署回放只验证特征及排序链路一致性，不将训练样本上的拟合命中率当作新的泛化提升。

验证程序 `pipeline/verify_turf_activation.py` 使用只读快照和补录文件：检查所有来源哈希，逐场比较冻结的 292 维特征、正式排名、印记和马券候选，并核对地方及泥地 12 组完整预测与切换前一致。输出只写入新的 `analysis_outputs/` 文件，不回写预测目录。

本次验证通过：630 场、8,324 条出走观察特征及正式排序逐值一致；印记与新前五一致、马券只从新前五选取；地方和泥地 12 组完整输出一致；2,520 份来源文件哈希未变。相关回归共 302 项，300 项通过、2 项因既有 HTML 样例缺失跳过，包括新旧模型调用隔离、无近走分支、市场信息隔离、校验失败、早期/最终回传、重复版本、结算及数据保留。

以后继续使用全部已结算合格 full 样本分折验证；不能将新模型回放其训练期比赛作为真实前向成绩。历史影子工具保留供旧记录分析；旧训练发布脚本绑定旧源码和模型哈希，不应绕过校验用来覆盖当前正式模型。
