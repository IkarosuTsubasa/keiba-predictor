# 中央草地正式模型

## 当前行为

中央草地使用 `central_turf_class_context_v1_20261025`，即用户在完整回溯和大头数、重赏分组比较后批准上线的“历史级别关系版”。保留原来的 292 维历史表现输入，新增 24 维当前级别与历史参赛级别的关系特征；分类器参数不变，在相同的 630 场合格样本上重新拟合。模型 SHA256：`553777c6e9eb601f6df0b616a70581cf356cd247ebe0817f85d849433b7eddd1`。

- 目标是预测前五尽可能覆盖实际前三；分类信号直接排序，混合权重为 1，不保留旧本命。
- 新排序在生成印记、投注策略、马券、模拟和 LLM 解释之前完成。这些下游模块沿用既有规则，但读取新排序。
- 不再加载旧草地冠军模型、旧草地前三模型，也不再后台计算影子结果。基础分项仍作为新模型的部分输入，不等于继续运行旧模型。
- 地方、中央泥地走原来的分支，模型文件与参数不变。
- 全部无近走记录的中央草地也使用新模型的缺失值处理，不交给 LLM 另选排名；此类数据不足的比赛不代表准确率已经验证充分。
- 不改历史预测，不做批量重生成、不删除原始数据或审计。已在运行中的旧代码任务仍可能回传旧版本结果。

正式模型和校验元信息位于 `keiba_llm_agent/models/scope_reranker/`。316 维特征由原有 28 维分项、204 维连续历史及相对特征、60 维补充历史，以及新增 12 维级别关系和对应 12 维同场相对值组成。新增输入使用明确的当前赛事级别和有效历史近走，保留未知级别的缺失状态。此前试验中的其他修正未合并上线。

特征不包含赔率、人气、身份或目标赛体重。启用市场分数的草地配置被拒绝；模型或输入校验失败时任务报错，不静默生成旧排序。

页面总分仍沿用原有排序映射分数，不把未经校准的分类信号宣传为真实前三概率。马券玩法、资金分配和信心算法没有在这次切换中重新优化。

## 部署生效

推送后由现有 Render 自动部署。远程预测由 GitHub Actions 检出对应分支代码执行；使用新代码启动的后续草地任务默认正式启用，不需要设置额外开关。`KEIBA_CENTRAL_TURF_SHADOW_MODE` 不再生效，历史总重排环境开关不关闭正式草地分支；其对地方和泥地的原有含义保留。底层 Python 的显式 `scope_reranker_enabled=False` 仍供离线分项实验使用，不是正常预测任务的默认值。

检查新预测的 `scope_reranker_result.model_version` 应为上述新版本，且 `applied=true`，`scope_reranker_config.mode=active`。首次线上回传与部署状态需要另行观测，代码推送成功不等于已确认远端首场生成成功。

## 数据与回溯

完整审计继续保存原始 `race_data`、各项分析、评分配置和最终预测。推理记录沿用 `model_inference.central_turf_history`，由其中的模型版本、特征版本与维度区分新旧模型，保存模型及源码哈希、训练截止日期、316 维特征及哈希、历史数据状态、分类信号、最终排序和前五；留档不会再次调用模型预测。现有阶段和版本化回传、结算继续保留这些扩展字段。含正式推理记录的早期审计及预测继续豁免清理，失败状态也保留；原有 `shadow_predictions` 历史记录不删除。本次不执行真实数据清理。

这次发布使用截至 2026-10-25 的全部 630 场合格中央草地 full、8,324 条出走观察训练出的冻结模型，其中 587 场原生完整审计、43 场重建完整审计。682 场完整记录中排除了 50 场经验时间污染和 2 场晚收到预测的记录；另有 176 场已结算的仅预测或缺审计记录，以及 1 场未结算记录，均未用于新逻辑回测。地方、泥地不在这次训练范围内。
