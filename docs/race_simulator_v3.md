# 模拟器指标与随机机制第三版

已实现可切换的研究模型，页面的模型选择中新增“履歴校正モデル（検証中）”。旧模型继续默认。原始预测、赛果、审计、快照和生产 Agent 排序均未修改。

## 改动

1. 速度使用历史完赛时钟相对条件参考的偏差，补入99,247条经过身份、日期、距离和名次核对的历史时钟。仍缺少时钟的近走使用收缩后的成绩指标。
2. 冲刺使用经过场地、距离、草地/泥地、马场状态修正的末段时间，取代原同场参赛马内部末段百分位。
3. 持久力结合末段位置变化，以及有时钟记录中的前段至最后600米速度衰减，与基础历史名次分开。
4. 对新近程度和距离接近程度加权，稀疏资料向先验值收缩。
5. 区分共同节奏、个体状态方差和估计不确定性；用训练残差及引擎对速度扰动的敏感度估计幅度。出闸延迟、节律、疲劳阈值、地形响应和进路机制仍有预设。

体力仍是潜在代理。耗力系数接近上界、节能系数接近下界，部分潜在参数不能独立识别；不得解释成真实生理测量。

## 数据和独立验证

开发：2026-07-07至10-31全部5,615场可用full样本，中央1,064、地方4,551，按日期分五折。上轮10月留出集已转为开发资料。缺少审计的1,692场不能重算；有效full中250场无近走、2,966匹无近走仍保留缺省值。没有做旧分数调权或v1—v6比较。

11月1日新快照在13:15日本时间捕获，共30,815个文件；原文件逐个校验，变化文件的内容与校验和同时获取。拟合程序不打开新快照。参数13:25:03冻结，新验证程序13:25:57才打开新赛果。两组比赛ID交集为零，但部分新比赛已经在冻结前发生，所以这是未见日期的回顾性留出，不能称为全部赛前预测。

新资料只有13场已结算且可用，中央11、地方2；另46场在快照截止时无赛果。每场采用与调参不同的128个种子，最终指标由JavaScript原版计算。模拟次数不增加真实样本量。

|指标|开发集原模型→新版折外|新13场原模型→新版|
|---|---:|---:|
|汇总前五覆盖实际前三席位|65.96%→69.12%|25/39→26/39|

“汇总”按反复模拟进入前三的频率排序；“单次”直接看每次动画的前五。新样本只多覆盖一个席位，单次排序和概率误差下降，仍为混合结果。中央汇总覆盖没有增加，地方仅两场，不能判断稳定增强，故不切换默认。

新比赛的最后600米标签为零，不能独立验证新日期冲刺精度；开发集末段误差约1.16秒只作开发证据。新样本完赛时间标签为159匹次。

## 结果与复现

完整报告、图、冻结模型和逐场结果在 `analysis_outputs/simulator_v3_20261101/`：

- `report.md`、`comparison.png`：完整对比。
- `frozen_model.json`、`freeze_receipt.json`：系数、参考模型、随机方差、冻结时间与哈希。
- `data_protocol.json`、`fit_protocol.json`、`new_validation_protocol.json`：来源、分折、种子、未见比赛与字段覆盖。
- `development_rows.json`、`new_rows.json`、`independent_validation.json`：逐场结果和独立重算。
- `parity.json`：加速版与原版668匹次对照，平均用时差0.00161秒、最大0.01118秒。
- `pending_*_predictions.json`、`pending_prediction_receipt.json`：快照中46场无赛果比赛的固定输出；缺精确发走时间，不保证全部早于发走。后续补赛果时使用冻结模型和这些输出，不根据结果调参。
- `run_source/`：与本次训练协议哈希一致的原始源码。

在新的实验目录复现，避免覆盖已冻结结果：

```powershell
python scripts/prepare_simulator_v3.py --previous analysis_outputs/simulator_calibration_20261101 --output analysis_outputs/simulator_v3_new_run
python scripts/optimize_simulator_v3.py analysis_outputs/simulator_v3_new_run
python scripts/validate_simulator_v3.py analysis_outputs/simulator_v3_new_run --snapshot analysis_outputs/render_agent_snapshot_20261101_simulator_v3
python scripts/report_simulator_v3.py analysis_outputs/simulator_v3_new_run
```

前端配置来自冻结模型，`scripts/export_simulator_v3_demo.py`可导出配置和三场输入样例，目标赛果不会进入前端。原`prepare_simulator_demo.py`仍只生成最初三场；重建展示资料后再执行第三版导出。

已通过20项前端模拟/布局测试、2项数据隔离测试和构建。浏览器确认新旧切换、拖动播放、200次统计与新日期输入可用，未发现控制台错误。独立代码重新核对新比赛覆盖席位和平均预测时钟误差，图表已检查。
